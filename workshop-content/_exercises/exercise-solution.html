2.4 In how many communes has the population decreased in 1 Person households, between 2012 and 2021?

Tip

1- Keep only the “1 Person” household sizes,

2- calculate the difference between the population registered in 2021 and 2012

3- keep only the rows for which the calculated difference is lower than 0.

4- Count the rows, you will have the answer.

5- Optional: keep only the relevant rows

6- Optional: arrange by the difference you calculated

Code 
communes_population %>% 
  filter(household_size == "1 Person") %>% 
  mutate(difference = x2021-x2012)  %>% 
  filter(difference < 0) %>% 
  select(commune, x2012, x2021, difference) %>% 
  arrange(difference)

4.1 Calculate the total population in 2021, by district.

Tip

Find a way to join together the communes_ids and communes_population data sets first. Then use group_by() and summarise() to compute the population of each district, in 2021 (sum the population of all communes in each district)

Code 
communes_population %>% 
  left_join(communes_ids, by = "commune") %>% 
  group_by(district) %>% 
  summarise(population = sum(`x2021`))

5.1 Transform the communes_population to long format

Tip

Create a communes_long by transforming the communes_population to longer format (use pivot_longer()).

Code 
communes_long <- communes_population %>% 
  pivot_longer(cols = x2012:x2021, 
               names_to = "year", 
               values_to = "population")

5.2 Summarise the data by canton and by year

Create a new tibble called canton_long, which is is the summarised version of communes_long.

1- You can see that you are missing the “canton” information in the communes_long, find a way to join district_ids and communes_ids to communes_long.

Code 
communes_long <- communes_long %>% 
  left_join(communes_ids, "commune") %>% 
  left_join(district_ids, "district")

2- Now create the tibble canton_population by grouping by canton and year, and summarising the data by canton. (The population of a canton is the sum of the population of each commune comprised in it).

Code 
canton_population <- communes_long %>% 
  group_by(canton, year) %>% 
  summarise(population = sum(population))
`summarise()` has grouped output by 'canton'. You can override using the
`.groups` argument.

6.1 Show the evolution of the population by canton.

To do so, draw a line per canton by mapping the color to the canton.

Tip

Map the year to the x and the population to the y. Use geom_line().

Code 
canton_population %>% 
  ggplot(aes(x = year, y = population, color = canton)) +
  geom_line()

6.2 Compare the population between 2012 and 2021, for the different cantons.

Create a horizontal bar blot, mapping the fill to the year so to have two separated bars, one for each year. In order to avoid stacking the bars on top of each other (the default in {ggplot2}), use can add the argument position = "dodge" to the geom_col().

Code 
canton_population %>% 
  filter(year %in% c(2012, 2021)) %>% 
  mutate(year = as.character(year)) %>% 
  ggplot(aes(y = canton, x = population, fill = year)) +
  geom_col(position = "dodge")

6.3 Create a plot per canton

Code 
canton_population %>% 
  filter(year %in% c(2012, 2021)) %>% 
  mutate(year = as.character(year)) %>% 
  ggplot(aes(y = population, x= year, fill = year)) +
  geom_col(position = "dodge") +
  facet_wrap(vars(canton), scales = "free_y")
