In diesem Notebook führen Sie eine erste Analyse der Schweizer Bevölkerung durch, mit der Sie anschliessend die folgenden Fragen beantworten können:

«Wie hat sich die Bevölkerung in den Schweizer Kantonen in den letzten 10 Jahren verändert?»

«Leben die Einwohnerinnen und Einwohner der Schweiz in grossen oder kleinen Haushalten?»

Um diese Fragen bestmöglich zu beantworten, haben wir Daten des BFS heruntergeladen und so umgeformt, dass Sie im Workshop damit arbeiten können.

Die Daten finden Sie im Ordner data von workshop-content. Von diesem Notebook aus lautet ihr Pfad ../data/.

Die folgenden Übungen sollen Ihnen helfen, das im Workshop Gelernte auf einen echten Datensatz anzuwenden.

Bereinigen Sie die Spalte year im zuvor erstellten Tibble canton_population, indem Sie das x entfernen.

  • Die resultierende Variable ist vom Typ «character»: Wandeln Sie sie in einen numerischen Typ um.

Siehe das Beispiel unten:

Code 
library(stringr)

my_data <- my_data %>%
  mutate(var_cleaned = str_remove(var_to_clean, "x")) %>%
  mutate(var_cleaned = as.numeric(var_cleaned))
