Markdown

Markdown is a simple “markup” language.

In a markup language you format a document with commands instead of menu items.

  • **two asteriks** to obtain bold text.

  • _underscores_ to produce italic text.

  • Headers, subheaders with #, ##, ###.

  • quote block with > the quote

Markdown can be rendered in various formats,

  • html

  • pdf

  • MSWord.

R Markdown

R Markdown

Combines text written with Markdown and code written with R.

This is useful in two ways:

  • As a tool for analysis:

    • R Markdown replaces scripts when carrying analyses.

    • You can execute the R Code contained in the R Markdown document to analyse your data.

    • Since it allows for text, it can be used to document your data analysis.

  • As a reporting tool

    • Can also produce reports in various formats, including .pdf, .docx, and html.

    • Rendering in html allows for some degree of interactivity

Quarto

Quarto is the next-generation version of R Markdown.

  • Designed to work with multiple languages and across multiple platforms and IDE’s.

    • Languages supported: R, Python, Julia, Observable.

    • IDE’s: RStudio, Jupyter Notebooks, VS Code, NeoVim.

  • Works seamlessly with R, since it is developed by Posit PBC (the company behind Rstudio IDE).

  • New versions of Rstudio IDE provide a Visual Quarto Editor.

    • This makes things easier, as there’s no need to know all the Markdown commands!

Note

The notebooks in this workshop are written in Quarto.

Create a new document

  • File -> New document -> Quarto Document…

YAML options

Look closely at the header of the template.

  • In any Quarto/R Markdown document, there’s a header written in YAML

  • In the header, we provide the rendering options.

For instance, you can add the basic document information

  • R Markdown
  • Quarto
title: "Working with R Markdown"
author: MYSELF
output: html_document
title: "working with Quarto"
author: MYSELF
format: html
editor: visual

Additionally, you can decide what type of editor you want to use in Quarto!

The YAML header can be populated with many options.

Note

We will be discussing these options at the end of the workshop

Insert a code chunk

  • Code can be written in R chunks.

    • There’s a +c button at the top of the script editor

    • Or with the shortcut Ctrl + Alt + i

  • The empty chunk looks like this:

    ```{r}

    ```

  • Here, you can insert some R code. For instance, there’s the object cars, which contains data on speed and break distance by a car.

    ```{r}

    cars

    ```

Execute a code chunk

  • To execute, use the play button ▶️ on the right-hand side of the chunk

  • Or with the shortcut Shift+Ctrl+Enter.

Knitting or the art of rendering a document

Once you’re done with your analysis, you can click on the button Knit/Render on the top of the Source file editor and produce a document

Exercise

Time to get the fingers dirty!

On your newly-created R Markdown / Quarto script:

  • Modify the YAML header add a title, author and date,

  • Write down some text, e.g. add a header and a small sentence

  • Insert a chunk

    • Add a couple of simple commands e.g. compute 5+5 and 30/6.

    • Execute the chunk with the play button or the shortcut.

  • After saving the file in a convenient location, Knit / Render this document.
